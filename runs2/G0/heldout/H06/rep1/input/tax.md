# 税务与换算规则（本单必须严格遵守）

## 1. 税率（按品类）

| category | 税率 |
|---|---|
| food | 0.13 |
| gadget | 0.071 |
| service | 0.0825 |
| book | 0.0 |

## 2. 金额定义

- `net_cents`：订单不含税金额，单位「分」；可以是负数（退款单）。
- `tax_exact`：`net_cents × 税率` 的**十进制精确值**。
- `tax_cents`：把 `tax_exact` 取整到「分」。
- `gross_cents`：`net_cents + tax_cents`。

## 3. 取整细则（全流程唯一允许的口径）

看 `tax_exact` 的小数部分：

- 小于 .5：向零方向取整（绝对值变小）；
- 正好等于 .5：**向远离零的方向**进位（`+136.5 → 137`，`−136.5 → −137`）；
- 大于 .5：向远离零的方向取整。

不许用「.5 进到偶数」的银行家舍入，也不许在乘完之后先做别的舍入再取整。

## 4. 换算成人民币

把 `gross_cents` 乘以 `fx.md` 里的汇率（1 单位外币 = ? CNY 分），得到 CNY 分，
再按第 3 节完全相同的 .5 口径取整。CNY 的汇率是 1。
