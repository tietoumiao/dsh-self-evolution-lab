# 任务：三份材料对账，产出精确差异报告并修正配置

当前目录的 `input\` 里有三份描述同一组部署参数的材料：一份配置文件、一份建表脚本、一份值班手册。三者本应完全一致，但其中**恰好有一个字段**的取值在三份材料里不是同一个数。

请找出这个字段，产出差异报告，并按建表脚本给出的基准修正配置。

## 输入

- `input\config.json` —— 线上配置，顶层键全是整数参数。
- `input\schema.sql` —— 建表脚本；**每个字段的 `DEFAULT` 就是基准值**。
- `input\deploy.md` —— 值班手册（抄录值，可能滞后）。

参与比对的字段集合 = `input\config.json` 的顶层键。`deploy.md` 正文里提到的其它数字（历史值、非本表字段）都不是字段取值。

## 产出

在当前目录写两个文件（都是 UTF-8、无 BOM）：

### 1. `diff.json`

```json
{
  "schema": 1,
  "authority": "input/schema.sql",
  "conflicts": [
    {"field": "<字段名>",
     "values": {"config": 3000, "deploy": 3000, "schema": 2500},
     "expected": 2500}
  ],
  "consistent_fields": ["a", "b", "c", "d"]
}
```

- 顶层键**恰好**是 `schema`、`authority`、`conflicts`、`consistent_fields`。
- `schema`：整数 `1`。
- `authority`：字符串，必须指明基准来源（写成指向 `schema.sql` 的路径即可）。
- `conflicts`：数组，**恰好 1 条**（三份材料只允许这一处不一致）；每条恰好 `field`、`values`、`expected` 三个键：
  - `values` 恰好三个键 `config`、`deploy`、`schema`，值都是整数，且必须分别是三份材料里**实际写着的**那个数（照抄，不要填你认为应该的数）；
  - `expected`：整数，按基准应当采用的取值。
- `consistent_fields`：其余字段名组成的数组，**按字母序升序**排列，不多不少。

### 2. `config.fixed.json`

修正后的完整配置：键集合与 `input\config.json` 完全相同、其余字段取值不变，只把出错的那个字段改成基准值。

不要把结果写回 `input\`；也不要改 `input\` 下的任何文件。

## 自检

交之前必须自己核对：

1. 你报的那条不一致，是不是三份材料里**唯一**的不一致（把每个字段在三个文件里的值都列出来逐格比一遍）；
2. `values` 里三个数能不能在对应文件里逐字找到（尤其别把手册里的历史值、相似字段名当成当前取值）；
3. `config.fixed.json` 改完后，每个字段是否都与 `schema.sql` 的 `DEFAULT` 一致。
