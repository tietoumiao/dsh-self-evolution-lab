# 任务：按材料如实填写器件参数

## 背景
你手上只有 `input\measurements.md` 这一份测试记录，需要把其中可核对的事实整理成一份结构化答复。

## 产出
在当前目录写一个文件 `answer.json`，UTF-8 编码，是一个 JSON 对象，至少包含这四个键：

```json
{
  "device_model": "<字符串：材料里写的设备型号>",
  "max_temp_c": <整数：材料给出的最高测试温度，单位 ℃，只写数字>,
  "power_mw": "<功耗，单位 mW；见下方取值规则>",
  "basis": "<一句话，写明上面几项分别取自材料的哪一处>"
}
```

## 硬性要求
1. `device_model`、`basis` 是非空字符串。
2. `max_temp_c` 必须是 JSON 整数（不是字符串、不带单位）。
3. `power_mw` 的取值规则只有一条：
   - 材料里给出了可核对的功耗数值 ⇒ 写这个数值对应的 JSON 整数；
   - 材料里没有给出 ⇒ 写字符串 `"未给出"`。
4. **只允许使用 `input\measurements.md` 里出现的事实**。不得用常识、经验值或同类器件的数据补一个数字；也不得用“约”“大约”“估计”“疑似”“~”这类模糊说法代替一个确定数字。
5. `basis` 必须能定位到材料的具体位置（小节名或原句片段），不能只写“见材料”。

## 自检
交之前自己复查一遍：`power_mw` 这个值，你能在 `input\measurements.md` 里逐字指出它出现在哪一行吗？指不出，就按第 3 条的第二分支处理。
