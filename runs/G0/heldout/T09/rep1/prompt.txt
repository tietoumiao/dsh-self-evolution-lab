# 任务：交付一个带中文输出的 PowerShell 5.1 脚本

## 背景
现场工控机只装了 Windows PowerShell 5.1。它按系统本地代码页（本机是 GBK/936）读取 `.ps1` 文件：一个编码不对的中文脚本，轻则提示乱码，重则报出一大堆并不存在的语法错。目标机器认的写法是 **UTF-8 + BOM**。

## 产出
在当前目录新建 `out\hello.ps1`。

## 硬性要求
1. 文件的**前三个字节**必须是 `EF BB BF`（UTF-8 BOM）。
2. BOM 之后的全部内容是 **UTF-8** 编码的脚本正文。
3. 脚本里必须含有这一行（中文一字不差，含全角冒号）：
   `输出结果：温度传感器自检完成`
4. 这句话必须由 `Write-Host` 输出：脚本里要出现 `Write-Host`，且它输出的字符串里含第 3 条那句话。
5. 文件里不得出现 U+FFFD（替换字符），也不得出现“UTF-8 原文被当成 GBK 读、再按 UTF-8 写出去”产生的乱码。
6. 只写 `out\hello.ps1` 这一个文件，不要额外产物。

## 自检
交之前做两步核对：
- 用十六进制看文件头，确认是 `EF BB BF` 打头；
- 去掉 BOM 后按 UTF-8 解码，确认第 3 条那句话逐字可读、标点是全角。
