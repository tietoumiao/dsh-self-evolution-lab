# 任务：修好时长解析与格式化模块

当前目录下的 `input\` 里有一个人写的 Python 模块，能跑但行为不对。请把它修好，产出可以直接导入使用的版本。

## 输入

- `input\intervals.py` —— 有缺陷的模块，含 `parse_interval` 与 `format_interval` 两个函数。
- `input\samples.json` —— 少量示例用例，形状为 `{"cases": [...]}`：`{"fn": 函数名, "args": [...], "want": 期望返回值}` 或 `{"fn": 函数名, "args": [...], "want_error": "异常类名"}`。

示例用例覆盖不全，只用来确认接口形状，别把它当完整清单。

## 产出

在当前目录写一个文件 `intervals.py`（就放在当前目录，不要放子目录，也不要改 `input\` 里的东西）。

## 契约

模块必须能在不产生任何副作用的情况下被 `import`，并导出下面两个函数（函数名一字不差）：

### `parse_interval(text: str) -> int`

把时长文本解析成总秒数（`int`）。

- 合法形状只有两种：`MM:SS` 与 `HH:MM:SS`。
- 每一组只能是 ASCII 数字字符 `0-9`，不允许前后空白、正负号、小数点、下划线、千分位。
- `MM` 与 `SS` 允许 1～2 位，取值必须在 `0..59`。
- `HH` 允许 1～5 位，取值不小于 0。
- 其它任何输入（空串、组数不对、超范围、含非法字符、不是 `str`）一律抛 `ValueError`；不要抛 `IndexError`、`TypeError` 之类别的异常，也不要返回 `None`。

### `format_interval(total_seconds: int) -> str`

把总秒数格式化成 `HH:MM:SS`。

- 小时位至少 2 位；超过 99 小时时按实际位数输出，不许截断或溢出。
- 分钟与秒恰好 2 位，补前导零。
- `0` 输出 `00:00:00`。
- `total_seconds` 为负数、或类型不是 `int`（`bool` 与 `float` 也算不是 `int`）时抛 `ValueError`。

## 自检

交之前必须自己验证：除示例用例外，把两种合法形状的边界（0 秒、59 秒、整分钟、整小时、两位小时、三位以上小时）以及各类非法输入的抛错行为都自己测一遍。
