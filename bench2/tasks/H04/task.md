# 任务：把原始流水压成一份逐字节确定的报表

当前目录下有一个 `input\raw.csv`（UTF-8、无 BOM、`|` 分隔，首行是表头）。
你要按下面的规则串成一条流水线，最终写出 `out\report.txt`。

## 处理步骤（必须按顺序，任何一步顺序错都会改变结果）

**第 1 步 · 读入**
逐行读 `input\raw.csv`。跳过表头（第一行）与空行（`strip()` 后为空）。
对其余每一行，先对整行做 **NFKC 规范化**（全角字符 → 半角），再判断是否为空。
按出现顺序给这些行编号 `seq`，从 1 开始，**只数数据行、不数表头与空行**；行被丢弃后编号不再重排。

**第 2 步 · 拆行与清字段**
按 `|` 拆分，必须恰好 7 段，否则整行丢弃。
每段先 `strip()`，再把该段内部**连续的空格/制表符压成一个半角空格**。

**第 3 步 · 字段规范化**
- `region`：转大写。
- `sku`：转大写；若它全部由数字组成，则左补 `0` 补到 5 位（`42` → `00042`，`7` → `00007`）；非纯数字则原样保留大写。
- `status`：转小写。
- `qty`、`unit_cents`：必须匹配 `^-?\d+$`（只允许可选负号加数字，不允许 `+`、空格、小数点），否则整行丢弃。
- `label`：只做第 2 步的清理，不改大小写。

**第 4 步 · 过滤**
只保留 `status` 属于 `paid` 或 `refunded`、且 `qty >= 1` 的行。

**第 5 步 · 计算与排序**
`total = qty * unit_cents`（整数分）。
排序键：先 `region` 升序（按码点比较），同一 `region` 内 `total` **降序**，
`total` 再相同则 `seq` **降序**。

**第 6 步 · 分组聚合**
按 `region` 分组；输出块的顺序就是它们在排序结果里第一次出现的顺序（即 `region` 升序）。每组算五样：
- `rows`：保留行数；
- `total`：组内 `total` 之和；
- `max`：组内最大的 `total`（可能为负）；
- `first`：排序后该组第一行的 `label`；
- `skus`：排序后该组每一行的 `sku` 用半角逗号连接，**不去重**。

**第 7 步 · 格式化写出**
金额格式：整数分 → 负号（仅当为负）+ 每三位加一个半角逗号 + `.` + 两位小数；`0` 写成 `0.00`，`-4500` 写成 `-45.00`。

写 `out\report.txt`（若 `out\` 不存在就建），**UTF-8 无 BOM、只用 `\n` 换行、
文件最后一个字节必须是 `\n` 且全文末尾只有一个 `\n`**。内容精确如下（`<...>` 是占位符，不要照抄尖括号）：

```
# summary v1
regions=<组数> rows=<保留行数>
== <REGION> ==
rows  : <rows>
total : <金额>
max   : <金额>
first : <label>
skus  : <sku,sku,...>
== <下一个 REGION> ==
...
--
grand_total=<所有组 total 之和的金额>
```

即：第一行固定 `# summary v1`；第二行是两段 `regions=`/`rows=`，用一个半角空格隔开；
每个组是一个 7 行的块（`== X ==`、`rows  : `、`total : `、`max   : `、`first : `、`skus  : `）；
所有组写完后是单独一行 `--`，最后一行是 `grand_total=<金额>`。

## 交付

当前目录下只需产出 `out\report.txt`，不要改动 `input\raw.csv`。
交付前请自己按上面的规则把整条流水线重算一遍，并确认：字节换行、末尾换行、千分位、符号、补零、以及 `total` 相同行的先后次序都与你的实现一致。
